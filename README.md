# 番茄钟 · Desktop Pomodoro Timer

一个基于 PyQt6 的桌面番茄钟应用,支持专注/短休/长休循环、系统托盘和专注统计。

## 功能

- 专注、短休、长休三种模式自动循环
- 系统托盘运行
- 专注记录与统计
- 可自定义各阶段时长

## 安装

需要 Python 3 环境。

```bat
install.bat
```

或手动安装依赖:

```bash
pip install -r requirements.txt
```

## 运行

```bat
run.bat
```

或:

```bash
python main.py
```

## 数据

专注记录保存在用户主目录的 `~/.pomodoro_data.json`。
